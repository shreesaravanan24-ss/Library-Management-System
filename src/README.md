#  Library Management System

A Spring Boot based **Library Management System** developed using Java. This project demonstrates a layered architecture with RESTful APIs for managing books, members, librarians, book issues, and book returns.

---

##  Features

-  Book Management
    - Add Book
    - Update Book
    - Delete Book
    - View All Books

- 👤 Member Management
    - Register Member
    - Update Member
    - Delete Member
    - View Member

-  Librarian Management
    - Add Librarian
    - Update Librarian
    - Delete Librarian
    - View Librarian

-  Book Issue Management
    - Issue Book
    - View Issued Books
    - Update Issue Details
    - Delete Issue Record

-  Book Return Management
    - Return Book
    - View Returned Books
    - Update Return Details
    - Delete Return Record
